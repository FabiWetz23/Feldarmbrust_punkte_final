# Sponsorenlogos

Fuer die spaetere EXE-Version liegt neben der `.exe` automatisch ein Ordner `Sponsoren`.

Einfache Bedienung:

1. Sponsorlogo als PNG/JPG in den Ordner `Sponsoren` kopieren
2. Webseite neu laden
3. Excel exportieren

Alternativ koennen Logos direkt auf der Webseite ueber `Sponsor hochladen` hinzugefuegt werden.

Die Logos erscheinen automatisch oben auf der Webseite und oben im Excel-Ausdruck.
